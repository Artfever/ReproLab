# The assistant

## What it is for

The assistant answers questions about how to use ReproLab and about one finished run. It reads a fixed set of short passages: the documents in docs/assistant and, when you pick a run, that run's log lines and manifest fields. It reads nothing else.

## What it will not do

It does not change a model or an input, does not approve or reject an analysis, and does not say whether a result is scientifically valid, has converged, or has any medical meaning. Questions asking for those judgements get a fixed decline message.

## Citations

Every answer must cite at least one passage id in square brackets, such as [states-02] or [run-log-L12]. The server checks that each cited id was among the passages it retrieved. An answer without a citation, or with an id that was not retrieved, is discarded and replaced by the decline message. The page shows each cited passage next to the answer, and every answer carries the label that it was generated by a language model.

## When there is no answer

If no passage matches the question well enough, the server returns the decline message without contacting any language model. When a run's log or manifest does not contain what you asked about, the answer should say the evidence is missing.

## Setting up a language model

The assistant needs an OpenAI-compatible chat endpoint. Set REPROLAB_LLM_BASE_URL and REPROLAB_LLM_MODEL in the server environment, and REPROLAB_LLM_API_KEY if the endpoint needs one. A local Ollama server at http://127.0.0.1:11434/v1 works. Without these settings the question box is disabled and the page says that no language-model endpoint is configured. If the endpoint does not reply to a probe within 3 seconds, the box is disabled and the page says it is unreachable.

## Limits

A question can be at most 500 characters. The text sent to the model is at most 6000 characters. A request to the model times out after 60 seconds. Failures are reported as unreachable, timeout, bad status or malformed reply.

## The key stays private

The key is read from the environment only. It is never written to a file, a response, an error message or a manifest.
