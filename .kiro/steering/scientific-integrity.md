# Scientific integrity

OpenBUGS produces numerical results. UI code may compute labelled summaries from actual samples. The AI assistant can explain a log and documentation but cannot invent, alter, approve, or medically interpret an analysis.

Every AI factual claim about engine behavior needs a real indexed manual section. Every claim about a specific run needs a real log line or artifact. When evidence is missing, say so. Preserve original input separately from any suggested edit. Do not describe a diagnosis or convergence judgment without a validated diagnostic method and explicit caveat.
