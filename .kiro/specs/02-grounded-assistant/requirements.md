# Requirements — grounded help

## User story

As a researcher, I can ask what a real OpenBUGS run error means and get a concise answer tied to the actual log and authoritative documentation.

## Acceptance criteria

1. Corpus has provenance, URL, version and reuse rights recorded for each source.
2. Retrieval returns relevant manual passages for known questions and an explicit no-evidence result for unsupported questions.
3. Responses include verified existing source links; claims about the run use actual log excerpts.
4. AI cannot execute tools, modify a model or silently send complete private data to a provider.
5. A small human-reviewed question set checks citations, harmful speculation and unsupported answers.
