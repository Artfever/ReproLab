Run an analysis

A run takes a model, data, initial values and a few settings, and executes in a container on this computer with no network access. Files are read in your browser and sent only to the local server.

  • Docker must be running and the local image must be built. See Documentation.
  • Only one run executes at a time.
  • A finished run is not a valid scientific finding and not a convergence claim.
