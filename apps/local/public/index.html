ReproLab local · OpenBUGS 3.2.3 and eight more legacy engines

Run an old analysis with its original engine, on this computer

ReproLab runs the OpenBUGS command-line workflow locally and does not translate the OpenBUGS language. You give it a model, data and initial values. It runs the original OpenBUGS engine inside a locked-down container on this computer and shows you the engine's real log and output files.

A finished run is not a valid scientific finding and not a convergence claim. ReproLab shows what the engine produced. It does not judge whether a model is appropriate, whether chains converged, or what the numbers mean.

CODA files written
  1. 01

    The engine's own words. Every line is written by OpenBUGS. The engine exits normally even for an invalid model, so ReproLab decides the state by finding seven of these lines in order.

  2. 02

    Files with checksums. This run wrote ten files. Each is listed with its size and SHA-256 checksum, and the manifest records the settings, engine version and image.

  3. 03

    Failures stay failures. A model with a syntax error ends as an engine error, and the engine's own message is shown as the reason.

What this is not

Read Limitations and Privacy before you start.

  • It is not a hosted service. Nothing is uploaded to a ReproLab server because there is none.
  • It is not an OpenBUGS replacement or a translator for the OpenBUGS language.
  • It is not validated for clinical, regulatory or publication use.

ReproLab is an open-source local tool. It runs OpenBUGS in a container on this computer. A finished run is not a valid scientific finding.
