Privacy

No data leaves this machine unless you use an optional assistant feature with a remote provider configured in your local .env.

What stays here

Models, data, initial values, logs, output files and manifests are stored in a folder on this computer. ReproLab has no account system, no analytics and no telemetry. Pages load no script, style, font or image from another site.

What an assistant call contains

If you enable the assistant, each question sends to your configured endpoint:

  • your question text, and
  • the text of the documentation passages retrieved for it.

Your model, data and initial-value files are never sent, unless their content appears in the current run's log lines that you ask about. If you point the assistant at a remote service, that service receives the call. With a local endpoint, nothing leaves your machine.

Voice input

Voice input is optional and disabled without a Groq API key. When you choose to record and transcribe a question, the browser asks for microphone access and sends that recording to Groq's Whisper transcription API. ReproLab does not save the audio. The returned transcript is shown in the question box; it is sent to your configured chat provider only if you choose Ask. You can type a question without using a microphone.

Deleting data

Delete the run folders under the local data directory, or use the reset script described in the README.

ReproLab is an open-source local tool. It runs OpenBUGS in a container on this computer. A finished run is not a valid scientific finding.
