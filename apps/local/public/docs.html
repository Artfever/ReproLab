Documentation

These notes are written by ReproLab for this local tool. They are not OpenBUGS documentation.

Requirements

  • Node.js 24.x.
  • Docker Desktop on Windows with WSL2, or Docker on Linux.
  • The local worker image built from the repository. You download the OpenBUGS source archive yourself. The repository does not contain it.

Start the app

The repository README gives the exact commands for your system. The server listens on 127.0.0.1 only.

Bundled demonstrations

  • Coin: a tiny model with a known analytic answer, written by ReproLab.
  • Coin, invalid: the same model with a deliberate syntax error, to show an engine error.
