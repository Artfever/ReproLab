Documentation

These notes are written by ReproLab for this local tool. They are not OpenBUGS documentation.

Requirements

  • Node.js 24.x.
  • Docker Desktop on Windows with WSL2, or Docker on Linux.
  • The local worker image built from the repository. You download the OpenBUGS source archive yourself. The repository does not contain it.

Start the app

The repository README gives the exact commands for your system. The server listens on 127.0.0.1 only. Run these from the repository root after placing your archive at vendor/OpenBUGS-3.2.3.tar.gz.

Windows PowerShell
powershell -ExecutionPolicy Bypass -File scripts\build-image.ps1
powershell -ExecutionPolicy Bypass -File scripts\start.ps1
Linux
scripts/build-image.sh
scripts/start.sh

Then open 127.0.0.1:8765 in your browser. To check the setup without starting anything, add -CheckOnly on Windows or --check-only on Linux.

Keyboard

  • Every control on every page works with Tab, Shift + Tab, Enter and the arrow keys.
  • In the assistant's question box, press Ctrl + Enter to ask.
  • On a narrow screen, Esc closes the open menu.
