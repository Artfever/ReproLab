Limitations

What this tool has not shown, stated before anything else.

A finished run is not a valid scientific finding and not a convergence claim.

Engine

ReproLab includes OpenBUGS 3.2.3 as its inference engine and runs it in Docker on your computer. Follow the README to build the local image and test the Coin example or the deliberate syntax error. ReproLab's own code is MIT licensed; OpenBUGS retains its own licence, listed in the repository's third-party notices.

Isolation

Docker Desktop isolation is the only isolation that has been tested. No other sandbox has been tested. Run only inputs you trust enough for that level of isolation.

Scope

  • One run at a time, small inputs only, a time limit of at most 300 seconds.
  • The OpenBUGS command-line workflow only. The language is not translated or repaired.
  • The assistant, when enabled, can be wrong. Check its citations.

ReproLab is an open-source local tool. It runs OpenBUGS in a container on this computer. A finished run is not a valid scientific finding.
